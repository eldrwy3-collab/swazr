# SWAZR.COM

Premium domain landing page for **SWAZR.COM** — a 5-letter `.com` domain available for acquisition, positioned for autonomous defense, drone, and AI innovation markets.

## Key Technologies

- **TanStack Start** (React SSR framework)
- **Tailwind CSS v4** (utility CSS, extended with custom properties)
- **Vite** (build tool)
- **Netlify** (hosting and deployment)

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:3000`.

## Structure

All page content lives in `src/routes/index.tsx` as a single React component. Styles are in `src/styles.css` using CSS custom properties (no Tailwind classes needed for this design).
